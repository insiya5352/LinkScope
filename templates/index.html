ABOUT THE PROJECT

Turning hyperlinks
into useful signals.

Web Page Link/Authority Mining applies graph theory to understand how pages connect and which pages occupy important positions in a link network.

Problem statement

Given a collection of directed hyperlinks, identify structurally important pages and compare their rankings using established graph algorithms.

Methodology

Validate CSV records → construct a directed graph → calculate PageRank, HITS and degree metrics → rank pages → visualize and interpret the output.

Algorithms and applications

NetworkX implements PageRank and HITS; in-degree provides a baseline. These methods are useful in web search research, citation networks, recommendation analysis and link-structure exploration.

Limitations

The result depends on the pages and links included in the dataset. This project does not crawl the full web or reproduce Google's complete ranking system.
